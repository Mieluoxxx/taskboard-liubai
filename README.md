# 留白 · Liubai Taskboard

把长期想做的事，落到这一周、这一天，然后按下计时器。

整个看板就是一个终端，但没有滚动区：每条命令都像先 `clear` 再执行，屏幕上永远只有当前这一幕，和上一条命令的结果。直接打字就是新增，`/` 开头是命令，鼠标点到的地方也都对应一条命令。

![留白终端：场景头、日计划关联树与提示符](docs/images/workspace.png)

**在线使用**：https://taskboard-liubai.vercel.app
**不想注册**：输入 `/demo`，演示板只留在你自己的浏览器里。

```
you@liubai > _
```

## 打字就是规划

```
you@liubai > 回复邮件                  + d3 回复邮件
you@liubai > 写周报 #blue ^w1          + d4 写周报        ← 蓝色，挂在本周 w1 下
you@liubai > /done d1 d3               [x] d1 … [x] d3 …
you@liubai > /mv d4 +1                 → d4 写周报 · 10-05
you@liubai > /start d2 25              ◉ 25 分钟专注开始
```

行首的 `g1` `w1` `d1` `f1` 是当前视图里的编号，`d1.1` 是子任务。改完不会多打一份视图，而是原地重画，改动的那一行闪一下。

## 关联是画出来的

```
留白 · 2026 Q4 › W40 09-28..10-04 › 10-04 周日              ◉ 深度工作 52:25
09-21 ━━━━━━━━━●──────────────────────────────── 12-31          第 14/102 天
W40 ‹  周一 09-28  周二 09-29  周三 09-30  周四 10-01  …  [周日 10-04]  ›
          ·           ·           ·           ●              6
g1    建立有余地的生活节奏
└─ w1    整理本周的注意力边界
   ├─ d1    [ ] 写下今天最重要的一步
   │  └─ d1.1 [x] 关掉一个通知入口
   └─ d2    [x] 回复读书会的邮件                              f3 ○ 25m
· 未关联
└─ d6    [ ] 买菜
```

每个视图都是同一棵「目标 → 周 → 日」树：当前这一层亮着、可以勾选；上层灰着当上下文。顶部的场景头是地图——项目时间轴上 `●` 是今天，亮的一段是你正在看的那一周或那一天；下面一条是这一周每天落了几件事。

- `/week`：每个周计划后面是 `一 二 三 … 日` 七格，`●○` 标出它落到了哪几天；一天都没落的写「未拆分」
- `/goals`：每个目标后面是若干周，标出它拆到了哪几周
- `/focus`：左边还是这棵树，专注块挂在各自的任务下；右边是一块钟，`/clock` 在表盘和像素数字之间切换

## 没做完的，会跟着你走

上一周没做完的周计划、昨天没做完的日计划，下次打开时会自己顺延到当前周期（周 → 本周，日 → 今天），并在行尾标出来源（`←W38`、`←09-20`）——你一眼就知道它是从哪一周、哪一天漂过来的。

原来那条会留在归档里，不覆盖、不消失，所以「这件事最初排在哪一周」一直查得到。挂在上层的关联也跟着走，不会断线。

## 专注

![专注计时进行中](docs/images/focus.png)

给一件事留一段不被打断的时间：`/start d1` 为日计划开始专注，这件事没做完的那块会接着计时，给时长（`/start d1 25`）才新开一块。倒计时挂在场景头的右上角和标签页标题上，到点后写出超了多少。可以 `/pause`，也可以 `/stop` 结束，记下的是实际用时。

专注页左边是当天的任务树，每件事下面挂着它的专注块；右边是一块钟——计时时是一块越吃越小的扇形，空闲时就是现在几点。

## 顺手的地方

- `/help` 列出全部命令，`↑↓` 选、回车执行；输入 `/` 会自动补全，`↑↓` 翻历史
- `Esc` 进入导航模式：`j/k` 移动、`x` 勾选、`e` 编辑、`p` 开始/暂停专注、`S` 结束、`J/K` 排序、`g/w/d/f` 切视图、`h/l` 翻页
- 场景写在地址栏里：浏览器的后退回到上一个视图，刷新停在原处
- `/help`、`/status` 这类长输出会整页盖住场景，`Esc` 收起
- `⌘K` / `Ctrl+K` 查找任务、项目和视图
- `/theme` 深浅色，`/lang` 中文 / English，包括保存失败、冲突、离线这些提示
- 断网或是两台设备同时改了：不会互相覆盖，能合并的自动合并，真的冲突才让你选（`/retry` `/sync` `/reopen`）

## 自己跑一份

需要 Node 24 与 pnpm：

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

后端用 Supabase：在终端里 `/login` 邮箱密码登录，每个账号只能看到自己的板。`supabase/migrations/` 里的 `001`–`010` 依次执行，再把 `VITE_SUPABASE_URL` 与 publishable key 填进 `.env.local`。已有部署先补齐迁移，再发布前端。

看板前端可以静态托管；MCP 连接器还需要 `api/` 中的 Node 24 服务端函数，推荐部署完整仓库到 Vercel。

界面字体是自托管的 Maple Mono NF CN，不请求任何第三方 CDN。

设计取舍与不变量见 [`docs/SPEC.md`](docs/SPEC.md)。

## Claude Chat / MCP

在 Claude 连接器中添加 `https://taskboard-liubai.vercel.app/api/mcp`，登录留白后授权自己的看板。支持 MCP 2026-07-28，并兼容 2025-11-25 等旧版客户端；不需要在聊天中提供密码或 API Key。

云端网页与 Agent 共用 30 天回收站和 90 天审计；完整读写、原子批量操作和冲突保护共用现有领域规则。在终端里输入 `/account`（或点侧栏的「连接 Claude」）可撤销授权、恢复数据；永久清除仅允许网页用户操作。

部署与最小验证见 [`docs/MCP.md`](docs/MCP.md)。
