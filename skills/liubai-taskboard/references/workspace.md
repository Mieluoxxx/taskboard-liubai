# 网页与本地使用

## 一次完整工作流

1. 登录自己的留白账号。未配置云端的本地实例可以选择 LOCAL DEMO，数据只存在当前浏览器，不会同步到云端。演示模式不提供 OAuth 或云端回收站。
2. 长期目标旁的周期轨道 →「新周期」→ 名称、开始／结束日期 → 保存。
3. 选中项目，在「长期目标」面板添加任务。
4. 周轨道选目标周，在「周计划」添加任务，并选择「关联上级」长期目标。
5. 日轨道选目标日，在「日计划」添加任务，并选择对应周任务。
6. 「专注块」添加标题、时长和可选日任务，保存后开始。暂停／继续控制计时；进行中可停止，到时点击结束。
7. 任务完成后自行勾选。下级完成不会自动完成上级。

## 编辑、排序、改期

- 点击标题／备注或编辑按钮查看完整内容。列表预览标题两行、备注五行；标题上限 450、备注上限 3000 个 UTF-16 码元。
- 添加子任务与关联上级是不同操作：子任务属于同一域和同一放置，上级关联跨长期／周／日三个域。
- 拖拽手柄或上移／下移调整同级顺序；不能跨列拖动来转换类型。项目也可拖拽排序。
- 键盘：手柄空格或回车提起／放下，上下键移动，Esc 取消。非输入状态 `←`／`→` 切面板，`1`–`4` 跳面板。
- 编辑顶层周／日任务的周次／日期可直接改期，子任务跟随。过去未完成任务上的「建议重新安排」用于向后顺延，原放置保留为归档。
- 项目周期不覆盖目标日期时，先由用户决定是否调整项目范围，不能通过解除关联绕过。

## 保存、回收站与授权

- 每次操作后检查顶部「已保存」。离线或失败时保留页面输入，联网后重试，不用强制刷新解决未保存问题。
- 表单冲突使用「重新打开编辑器」或「加载最新（保留草稿）」；直接操作冲突需核对最新状态后重做。只有明确放弃才丢弃草稿。
- 云端看板设置中的「授权、回收站与审计」打开 `/account`；存在未保存改动时先解决保存问题。
- 删除项目包含其任务、子任务和顺延归档，专注块保留。云端删除集合可在 30 天内恢复，超过期限不可恢复；永久清除不可撤销。
- 在账户页面查看已授权客户端并撤销访问。客户端名称是第三方自行声明的，授权前核对 ID 和返回地址。
- 顶部或设置可切换中英文；语言仅保存为浏览器偏好。时区在设置中修改。

## 本地开发（仅在已克隆的项目仓库中执行）

需要 Node 24 和 pnpm。只体验本地演示、不改变现有配置：

```bash
pnpm install
VITE_SUPABASE_URL= VITE_SUPABASE_PUBLISHABLE_KEY= pnpm dev
```

云端部署按仓库 `docs/MCP.md` 操作；`.env.local` 只在不存在时从 `.env.example` 复制，禁止覆盖既有凭据。数据库按顺序执行迁移至 `006_agent_access.sql`，再部署前端与 MCP 函数。MCP 不是纯静态文件，单独托管 `dist/` 不会提供连接器。

最小验证：`pnpm test:agent` 和 `pnpm build`。不要为提供使用说明擅自执行数据库迁移、创建测试任务或停止真实计时器。
